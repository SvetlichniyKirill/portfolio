# Портфолио — режиссура по скроллу + WebGL

Одностраничник с инерционным скроллом, запиненной горизонтальной галереей,
3D-блобом на шейдерах и искажением обложек по наведению.
Ванильный JavaScript, никакого React.

---

## Как запустить

ES-модули не работают по `file://` — браузер блокирует их CORS-политикой.
Двойной клик по `index.html` покажет пустую страницу, это нормально.

```bash
python serve.py --open
```

Откроется <http://127.0.0.1:5173/>. Правки в CSS/JS видны после F5
(кэш отключён на стороне сервера).

## Стек

| Пакет | Зачем | Вес |
|---|---|---|
| [Lenis](https://github.com/darkroomengineering/lenis) | инерционный скролл | ~3 КБ |
| [GSAP](https://gsap.com/) + ScrollTrigger | вся анимация и пиннинг | ~70 КБ |
| [OGL](https://github.com/oframe/ogl) | WebGL: 3D-сцена и шейдеры картинок | ~30 КБ |

Пакеты приходят с CDN через **карту импортов** в `<head>` файла `index.html`.
Это замена сборщику: код пишется с обычными импортами (`import gsap from 'gsap'`),
а браузер сам подставляет URL. Node.js для запуска не нужен.

## Приёмы: что где смотреть

**1. Инерционный скролл** — `modules/smooth-scroll.js`
Половина ощущения «дорогого сайта» за 20 строк. Критическая деталь:
`ScrollTrigger.update()` вызывается из колбэка Lenis, а `lenis.raf()` —
из тикера GSAP. Два независимых rAF-цикла рассинхронизировались бы,
и пиннинг дёргался бы на кадр.

**2. Горизонтальный скролл** — `modules/works-scroll.js`
Секция пиннится на весь экран, длина прокрутки искусственно равна
ширине трека минус экран, трек едет по X через `scrub`.
Всё, что зависит от размеров, задано функциями плюс `invalidateOnRefresh`.

**3. Текст по символам** — `lib/split.js` + `modules/intro.js`
Маска ставится на **строку**, не на символ: per-char `overflow: hidden`
обрезал бы хвосты у «у», «ц», «р». Исходная фраза уезжает в `aria-label`,
осколки помечаются `aria-hidden` — скринридер читает предложение целиком.

**4. Слова по скроллу** — `modules/reveals.js`
`stagger: 1` при `duration: 1` даёт окна слов друг за другом без наложения,
`scrub: true` привязывает прогресс к позиции — текст загорается под взглядом.

**5. 3D-блоб** — `gl/hero-blob.js`
Сфера 128×128, вершины смещаются симплексным шумом вдоль нормали.
Три октавы: крупная форма, рябь, крошка. Цвет — не текстура, а френель:
чем ближе поверхность к силуэту, тем сильнее акцент.

**6. Искажение обложек** — `gl/image-plane.js`
Здесь главная архитектурная развилка. Обычно такие галереи делают одним
канвасом на весь экран и вручную синхронизируют позиции DOM и плоскостей —
красиво в демо, мучительно при пиннинге и ресайзе.
Здесь **у каждой карточки свой канвас внутри неё**: позицию считает браузер,
шейдер знает только свой прямоугольник. Работает внутри горизонтального
трека без единой правки.

## Производительность и доступность

- `dpr` ограничен 1.75 (1.25 на тач) — 3x убивает fps без видимой выгоды.
- Рендер останавливается, когда канвас вне вьюпорта (`IntersectionObserver`).
- Анимируются только `transform` и `opacity`.
- `prefers-reduced-motion: reduce` выключает Lenis, WebGL, курсор и зерно;
  контент остаётся полностью читаемым.
- Свой курсор включается только при `hover: hover` и `pointer: fine`.
- На тач-устройствах пиннинг заменён нативным свайпом со `scroll-snap` —
  привычнее и не воюет с адресной строкой мобильного браузера.
- Стартовые состояния ревилов ставит JS, а не CSS: если скрипт не загрузился,
  контент виден, а не спрятан навсегда.

## Что заменить под себя

| Что | Где |
|---|---|
| Имя, тексты, ссылки | `index.html` |
| Палитра | `styles/base.css`, блок `:root` |
| Цвета блоба | `src/gl/hero-blob.js`, `uColorA/B/C` |
| Оттенок обложки проекта | атрибут `data-hue` на `<article class="work">` |

### Реальные скриншоты вместо процедурных обложек

Обложки сейчас рисуются на canvas (`lib/cover.js`): mesh-градиент, сетка,
кольца, зерно. Ноль сетевых запросов и никаких «placeholder.com».

Когда появятся скриншоты — положи их в `images/` и добавь атрибут:

```html
<canvas class="work__gl" data-gl-work data-src="images/master-site.jpg"></canvas>
```

Шейдер и вся логика те же, обложка просто подменяется после загрузки.

## Переезд на Vite

Когда встанет Node.js:

```bash
npm install
npm run dev
```

Затем удалить из `index.html` блок `<script type="importmap">` — импорты
пойдут из `node_modules`. Больше менять нечего: специально написано так,
чтобы код не отличался от сборочного. `serve.py` после этого не нужен.

## Деплой

Статика без бэкенда, поэтому подойдёт что угодно:

- **Vercel / Netlify** — перетащить папку, готово. Без сборки указать
  корень проекта как publish directory.
- **GitHub Pages** — залить в репозиторий, включить Pages в настройках.

Единственное требование к хостингу — отдавать `.js` с
`Content-Type: text/javascript`. Все перечисленные это делают.
